GOWTHAMA PORTFOLIO WEBSITE

Files:
- index.html       Home page
- about.html       About page
- skills.html      Skills page
- projects.html    Projects page with working category filters
- contact.html     Accessible contact form demo
- style.css        Your supplied Figma-derived stylesheet
- script.js        Your supplied interaction script
- assets/images/   Optional images

HOW TO RUN:
1. Extract this folder.
2. Open the folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html and choose "Open with Live Server".

IMPORTANT BEFORE PUBLISHING:
- Replace "your.email@example.com" in contact.html with your real email address.
- Update LinkedIn links to your actual profile URL.
- Update the canonical example.com URLs in each HTML head to your real deployed domain.
- Add your own project links, screenshots and any details you want to correct.
- The contact form currently validates in the browser only. It does NOT send email.
- Project descriptions are starter content; review them for accuracy before publishing.

ACCESSIBILITY NOTES:
- Semantic header, nav, main, section, article, footer and form elements are used.
- Skip link, keyboard-visible focus, accessible menu button, labels, error associations and live status messages are included.
- Test with keyboard and Lighthouse after adding your final content.
